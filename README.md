# Snake Arcade

A responsive browser-based Snake game built with plain HTML, CSS, and JavaScript. No framework or build step is required.

## Run locally
Open `index.html` in a modern browser.

## Deploy to Vercel
1. Upload these files to a GitHub repository:
   - `index.html`
   - `style.css`
   - `script.js`
2. In Vercel, choose **Add New → Project** and import that GitHub repository.
3. Keep the framework preset as **Other**.
4. Leave Build Command and Output Directory empty (or use the repository root as the output directory).
5. Click **Deploy**.

Vercel will serve the static site directly. No Python runtime or backend is needed.

## Controls
- Arrow keys or WASD: move
- Space: pause/resume
- Enter: start/restart
- Mobile: on-screen controls or swipe on the game board

The personal best is stored in the browser on the current device.
